# Kontext

[ISO 6414](/normen/iso-6414-glaszeichnung.md) Abschnitt 4.1 verlangt, Glas in technischen Zeichnungen
undurchsichtig zu zeichnen; nur wo man eine Skala abliest, wird es durchsichtig (4.2).

# Entscheidung

ChemLab zeichnet Glas immer durchsichtig: Kontur, schwache Glasfläche, Glanzlicht, Inhalt sichtbar.

# Begründung

ChemLab ist eine Simulation, keine Fertigungszeichnung. Farbumschläge, Niederschläge, Gasblasen
und Füllstände sind das, worum es geht. Das entspricht der gängigen
[Versuchsskizze](/normen/versuchsskizze.md). Die übrigen Regeln von ISO 6414 (Wandstärke,
Schliffkennzahl) werden übernommen.
